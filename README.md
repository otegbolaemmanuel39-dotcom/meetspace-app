# MeetSpace - Your World. Your People.

A social hangout platform: themed rooms, games, discovery.
Plain HTML, CSS and JavaScript. Supabase backend (from Milestone 3).

## Run locally
1. Open this folder in VS Code.
2. Install the "Live Server" extension (Ritwick Dey).
3. Right-click index.html and choose "Open with Live Server".

## Files
- index.html          the page
- style.css           all styling
- app.js              all behaviour
- config.js           shared settings (Supabase keys later)
- database_setup.sql  database tables and security rules (Milestone 3)
- manifest.json, service-worker.js, icons/   installable-app support
- netlify.toml, _headers   deployment settings (Milestone 7)
